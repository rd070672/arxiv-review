# LLM エージェントによる支配方程式の自律的探索

- **執筆日**: 2026-05-30
- **要旨**: 材料科学の支配方程式（Hall-Petch 則・Paris 則など）は 1 世紀以上かけて人間の実験的洞察から発見されてきた。本論文（arXiv:2604.19789）は、LLM が方程式の想起・コード生成・モデル検証を反復するエンドツーエンドのエージェントフレームワークを構築し、Hall-Petch 則・Paris 則の自律的な回復（R² = 0.95）、より専門的な Kuhn の HOMO-LUMO ギャップ方程式の部分的回復、さらにひずみ依存 Kuhn 方程式という新規方程式候補の提案を達成した。しかし同時に、物理的に誤った方程式が統計指標（R² の差わずか 0.0006）をパスしてしまうという「もっともらしいハルシネーション」問題が明確に示された。「数値適合度の良さ＝科学的正しさ」という等号が成り立たないこと——これが LLM 駆動の自律的理論発見において残された根本的な課題である。
- **タグ**: `AI-for-materials-science` / `symbolic-regression; materials-theory; LLM-agent` / `ReAct-loop; chain-of-thought; nonlinear-regression`
- **anchor 論文**: [arXiv:2604.19789](https://arxiv.org/abs/2604.19789) — Samuel Onimpa Alfred, Veera Sundararaghavan (University of Michigan), 2026
- **参照論文数**: 7本
- **この記事の中心的な問い**: LLM エージェントは材料科学のデータから支配方程式を人間の介在なしに「回復」できるか。またハルシネーション（もっともらしい誤り）は通常の検証指標では検出できない——この問題をどう克服すべきか。

## 1. なぜ今このテーマか

材料科学の発展史は「データから法則を読む」という行為の積み重ねである。1889 年にアレニウスは複数の実験者が報告した温度依存反応速度データを精査し、それらが共通の数式 $k = A e^{-E_a/RT}$ で統一できることを示した——アレニウス方程式の誕生である。1950 年代には Hall と Petch が独立に多結晶金属の引張試験データを整理し、降伏応力と結晶粒径の逆平方根関係（Hall-Petch 則）を見出した。1961 年に Paris は疲労き裂進展速度と応力拡大係数の対数-対数プロットに線形領域があることに気づき、Paris 則を定式化した。これらの発見に共通するのは「人間がデータの背後にある構造を洞察し、関数形式を提案し、フィッティングで確認する」という反復プロセスだ。

近年の材料インフォマティクスは「物性の予測」では目覚ましい成果をあげているが、「法則の形式的発見」は依然として人間の専門的洞察に依存してきた。グラフニューラルネットワークは新物質のバンドギャップを高精度で予測できるが、予測の根拠となる「構造-物性の法則」を明示的な数式として出力しない。記号回帰（Symbolic Regression）はこのギャップを埋めようとするが、方程式空間の探索は指数的に広大であり、ドメイン知識なしには物理的に意味のある数式を効率的に見つけることが困難だった。

ここに LLM の強みがある。LLM は科学文献の大規模学習を通じて材料科学の典型的な関係式の形・物理的意味・適用条件を暗黙的に内包している。この知識を「方程式形式の賢い提案」に活用し、数値フィッティングと検証のツールセットと組み合わせることで、「自律的な法則発見エージェント」が実現できる——それが本論文の中心的アイデアである。

## 2. 何が新しいのか

### フレームワーク設計：ReAct ループと 3 コンポーネント構成

著者らは ReAct（Reasoning and Acting）パラダイムに基づく自律エージェントを MATLAB R2025b で実装した（論文 Fig. 1）。フレームワークは 3 つの主要コンポーネントで構成される。

第一の推論エンジン（Reasoning Engine）は GPT-4 または GPT-5 であり、タスク全体の文脈・利用可能なツールのスキーマ・エージェント状態・直近の推論履歴からなる構造化プロンプトを受け取り、次のアクションを決定する。

第二のツールレジストリ（Tool Registry）は 8 つのコアツールを提供する（論文 Table 1）。

| ツール | 目的 |
|---|---|
| load_data | データの読み込み |
| generate_function | LLM の知識から物理方程式を生成 |
| fit_model | 非線形最小二乗法によるパラメータ最適化 |
| test_function | 生成した関数の構文・物理的妥当性のテスト |
| validate_fit | R²・RMSE・残差の計算 |
| create_plots | 診断プロットの生成 |
| export_results | 結果の保存 |
| finalize | タスク完了の宣言 |

第三のエージェント状態（Agent State）は作業メモリであり、読み込んだデータ・生成した関数・フィッティング済みパラメータ・検証指標・全推論ステップの履歴を保持する。

エージェントは各反復で以下の 3 ステップを実行する（論文 Fig. 2 の構造化フォーマット）：

```
THOUGHT: <現在の状態に関する推論と次のステップの計画>
ACTION: {"tool": "<ツール名>", "input": <JSON入力>}
OBSERVATION: <ツールの出力、状態を更新し次の反復に反映>
```

**設計上の重要な制約**：`generate_function` ツールにはフォールバック（ハードコードされた方程式）が一切存在しない。LLM が方程式の生成・コード変換・関数テストのいずれかのステップで失敗すれば、エージェントは即座に停止する。この厳格な設計により「完了したタスク」は真に LLM の科学的理解を反映することが保証される。

### ケーススタディ1：Hall-Petch 則の回復

**データ**：複数の金属の平均結晶粒径 $d$（μm）と降伏応力 $\sigma_y$（MPa）の実験値（文献 [27] より抽出）。

論文 Appendix A.1 の完全な推論トレースには、7 イテレーションで完遂されるワークフローが記録されている。主要なイテレーションを示す。

イテレーション 2 で `generate_function` を呼び出すと、LLM はパラメトリック知識から以下の方程式を生成した：

```
σ = σ0 + ky * d^(-1/2)

- σ: 降伏応力 (MPa)
- σ0: 格子摩擦応力/切片 (MPa)
- ky: Hall-Petch 強化係数 (MPa·μm^(1/2))
- d: 平均粒径 (μm)
```

イテレーション 3 で初期推定値（`initial_sigma0 = 90, initial_k = 10`）を与えて `fit_model` を実行し、イテレーション 4 で `validate_fit` を実行した結果：

$$\sigma_y = 38.46 + 9.48\, d^{-1/2}, \quad R^2 = 0.9499, \quad \text{RMSE} = 7.36\ \text{MPa}$$

GPT-4・GPT-5 ともに同じ方程式形式を正確に生成し、両モデルで失敗は一切なかった。論文 Fig. 6 は実験データ点（青丸）とフィット曲線（赤線）の一致を示す。

### ケーススタディ2：Paris 則の回復

**データ**：レーザー粉末床溶融（L-PBF）で製造した Ti-6Al-4V の垂直方向試験片に対する疲労き裂進展（FCG）試験データ（応力比 $R = 0.1$）。

Paris 則は疲労き裂進展速度の式

$$\frac{da}{dN} = C\,(\Delta K)^m$$

（$da/dN$：1サイクルあたりのき裂進展量、$\Delta K$：応力拡大係数範囲、$C$・$m$：材料定数）が成立するのは FCG 曲線全体ではなく、「Region II（安定き裂進展域）」のみである。このため、エージェントはデータの適用範囲を自ら特定してからフィッティングを行う必要があった。

`auto_select_region` ツールにより、GPT-4・GPT-5 はほぼ同一の Region II を検出した：ΔK 範囲 [3.808, 36.838] MPa√m（29 データ点）、検出された対数-対数傾きの範囲 [2.66, 3.78]。両モデルとも 9 イテレーションで完了し、失敗なし。論文 Fig. 7 はログ-ログスケールでの Paris 則フィッティングを示す。

### ケーススタディ3：Kuhn 方程式の部分的回復——「もっともらしいハルシネーション」の発見

これがこの論文で最も重要な知見をもたらしたケーススタディである。

**物理的背景**：共役有機系の HOMO-LUMO ギャップは、Kuhn 方程式

$$\Delta E = \frac{h^2}{8mL^2}(N + 1) + V_0\!\left(1 - \frac{1}{N}\right) \tag{1}$$

で記述される。ここで $N = 4n + 2$ は π 電子数、$h$ はプランク定数、$m$ は電子質量、$L$ は共役経路に沿ったジグザグ長、$V_0$ は無限長鎖の HOMO-LUMO ギャップ（フィッティングパラメータ、$\approx 1.6$ eV）である。本論文のデータは、ヘリセン（$n = 6$〜16 ベンゼン環）を DFT(LDA) で計算した HOMO-LUMO ギャップである（文献 [29]）。

**知識想起タスク（文献参照なし）** の結果（論文 Table 2）：

| エージェント | 生成された方程式 |
|---|---|
| GPT-4 | $\Delta E = \dfrac{h^2 N}{8mL^2} + V_0$ |
| GPT-5 | $\Delta E = \dfrac{h^2(N+1)}{8mL^2} + V_0$ |

GPT-4 は $(N+1)$ の代わりに $N$ を、$(1-1/N)$ 項を完全に省略した。GPT-5 は $(N+1)$ は正しいが $(1-1/N)$ 項を省略した。

しかしここに驚くべき事実がある。両モデルとも R² > 0.97 の高い適合度を達成した：
- GPT-4 近似形：$V_0 = 0.058785$ ハートリー（1.5996 eV）、$R^2 = 0.9764$、RMSE = 0.0303 eV
- GPT-5 近似形：$V_0 = 0.058098$ ハートリー（1.5809 eV）、$R^2 = 0.9712$、RMSE = 0.0334 eV

なぜ誤った方程式で高い R² が得られるのか。$(1-1/N)$ 項は $N = 16$ で $1 - 1/16 = 0.9375$、すなわち 1 からわずか 6.25% の偏差しかない。この補正項の欠如はフィッティングパラメータ $V_0$ のわずかな調整によって吸収されてしまうのだ。

**文献抽出タスク（論文 PDF/HTML へのアクセスあり）**：

GPT-5 搭載エージェントは PDF 抽出失敗（出力 1 文字）を認識して HTML 抽出に切り替えた（論文 Fig. 9 の推論トレース）：

```
ITERATION 3
THOUGHT: The PDF is downloaded; next I should extract its text to
locate Kuhn's equation.
ACTION: {"tool": "extract_text", "input": {}}
OBSERVATION: Extracted 1 characters from PDF: ...

ITERATION 4
THOUGHT: The PDF text extraction failed (only 1 character). I should
extract Kuhn's equation from the arXiv HTML instead.
ACTION: {"tool": "extract_equation_html", "input": {"paper_id": "2303.03490v1"}}
=== Extracted Equation ===
\Delta E = \frac{h^2}{8mL^2}(N+1) + V_0\left(1 - \frac{1}{N}\right)
```

GPT-5 は完全な正規形を抽出し、$V_0 = 0.059506$ ハートリー（1.6193 eV）、$R^2 = 0.9770$、RMSE = 0.0299 eV を達成した。一方 GPT-4 は PDF 抽出のエラーメッセージを有効な出力として処理し（！）、不完全な方程式で継続した。

**核心的洞察**：正しい方程式（GPT-5 文献抽出）と誤った方程式（GPT-4 知識想起）の R² の差は わずか 0.0006（= 0.9770 − 0.9764）である。これは「数値的適合度の良さが科学的正しさを保証しない」という根本的問題を実証する。

### ケーススタディ4：ひずみ修正 Kuhn 方程式——新規方程式候補の提案

ヘリセンに機械的ひずみを加えると HOMO-LUMO ギャップが変化するが、引張（正のひずみ）と圧縮（負のひずみ）で非対称な応答を示す。引張では 25% ひずみで最大を持つ急峻な放物線的増加、圧縮では緩やかな逆放物線的減少が観察される。文献にこの応答を記述する標準方程式は存在しない。

エージェントに対してはベース Kuhn 方程式のみが提供され、ひずみ効果の関数形は LLM が自ら生成する必要があった。GPT-5 搭載エージェントが生成した方程式（論文 Eqs. 3〜5）は：

$$\text{strain\_kuhn}(\epsilon) = \frac{h^2(s + 1)}{8m\!\left[l_0\!\left(1 + \delta(\epsilon)\right)\right]^2} + v_0\!\left(1 + \gamma(\epsilon)\right)\!\!\left(1 - \frac{1}{s}\right) \tag{3}$$

ここで区分関数 $\delta(\epsilon)$ は

$$\delta(\epsilon) = \begin{cases} \epsilon, & \epsilon \leq 0 \\ \epsilon^2, & \epsilon > 0 \end{cases} \tag{4}$$

およびひずみ修正項

$$\gamma(\epsilon) = 2.5\,\epsilon\!\left(1 - \frac{\epsilon}{0.25}\right), \quad \text{for all } \epsilon \tag{5}$$

と定義される。しかし両エージェントともにランを変えるたびに異なる関数形を生成し（「機能的不安定性」）、失敗することもあった。GPT-4 は最大 10 イテレーション、GPT-5 は通常 4〜5 イテレーションを要した。論文 Fig. 11 が複数ランの代表的出力を示す。

## 3. どこまで分かったのか

### 4 種類のハルシネーション失敗モード

本論文の最も重要な貢献の一つは、ハルシネーションの種類を系統的に分類したことである（論文 Section 4.1）。

**失敗モード 1：もっともらしいハルシネーション（Plausible Hallucination）**

エージェントが科学的に誤った方程式を生成するが、それが標準的な検証指標をパスしてしまうケース。Kuhn 方程式ケースがその典型例であり、R² の差はわずか 0.0006 であった。正しい物理構造（$1/L^2$ 依存性）を保ちながら、細部の補正項（$(1 - 1/N)$）を省略した「プラシーボ方程式」が生成された。

**失敗モード 2：確信に満ちた継続（Extraction Failure with Confident Continuation）**

GPT-4 は PDF テキスト抽出が失敗して「1 文字」しか返ってこなかった際、エラーメッセージを有効な方程式テキストとして処理し、次のステップ（コード生成）に進んだ。自分が失敗していることを認識できない。

**失敗モード 3：機能的不安定性（Functional Instability）**

ひずみ修正 Kuhn 方程式のように正解が存在しない開放的なモデリングタスクでは、エージェントは毎回異なる関数形を生成した。それぞれのランが「成功」を報告しながら、異なる数学的表現を提案する。

**失敗モード 4：純粋な捏造（Pure Fabrication）**

科学的根拠のない関数形を発明するケース。ひずみ修正タスクで確認された。

### GPT-4 と GPT-5 の比較

4 つのケーススタディにわたる GPT-4 と GPT-5 の性能を整理すると以下のようになる。

Hall-Petch および Paris 則では両モデルが同等の正確な性能を示した。Kuhn 方程式では、知識想起では GPT-4 が $(N+1)$ 因子も欠落（より不完全）、GPT-5 は $(N+1)$ は正しいが $(1-1/N)$ を欠落した。文献抽出では GPT-5 は自律的に抽出方法を切り替えて完全な方程式を回復したが、GPT-4 はエラーに気づかず不完全な抽出で継続した。ひずみ修正タスクでは GPT-5 が少ないイテレーション（4〜5 回対 10 回）でより効率的に機能した。

この比較が示す核心的知見は「エピステミック自己認識（epistemic awareness）」の差だ。GPT-5 は自分の知識の境界を認識して代替戦略に切り替えられるが、GPT-4 はそれができない。自律的科学エージェントにとって「失敗を認識する能力」は「正しく答える能力」と同等かそれ以上に重要である、というのが著者たちの主張だ。

### 結果の確からしさと「回復 vs. 記憶」問題

本論文が正直に認めている重要な限界は、「データから推論した」のか「学習データから記憶を引き出した」のかの区別が困難な点である。Hall-Petch 則・Paris 則は教科書に掲載される普遍的な知識であり、データなしでも LLM が同じ答えを返せる可能性がある。

著者はこれに対して「フォールバック方程式を一切提供しない」設計で対応している（もし LLM が方程式を生成できなければエージェントは停止する）。しかし、より根本的なブラインドテスト——「LLM の学習データに含まれない人工的な未知法則」に対してエージェントをテストする——は本論文の実施範囲を超えている。

## 4. 研究の流れの中でどう位置づくか

記号回帰（Symbolic Regression）は 2000 年代から「データから数式を発見する」研究として発展してきた。遺伝的プログラミングベースの AI Feynman（arXiv:1905.11481）は物理的拘束（次元解析・対称性・可分性）を使って数式空間を効率的に探索し、Feynman Lectures の 100 方程式の多くを回復した。PySR（arXiv:2305.01582）はより汎用的な実装を提供し、科学者が日常的に使えるツールとして普及した。

これらの記号回帰は「ドメイン知識なしに数式空間を探索する」という性格をもつ。本論文の LLM アプローチはここに「ドメイン知識による賢い探索」という次元を加えた。LLM は「この種のデータにはこの型の方程式が合いそう」という広大な事前知識を活用でき、記号回帰が陥りがちな「物理的意味のない複雑な数式」を最初から回避できる。

The AI Scientist（arXiv:2408.06292）は仮説生成・実験実行・論文執筆の完全自動化を目指すより野心的なフレームワークだが、本論文は「支配方程式の発見」という単一のタスクに特化することで評価の明確さを得た。

ReAct ループ（Yao et al., arXiv:2210.03629）は LLM の推論（Reasoning）と外部ツールの行動（Acting）を統合するパラダイムとして本論文の直接的な設計基盤となっている。ReAct の思想は「LLM が知識を内包しながら、必要な計算は外部ツールに任せる」という役割分担を可能にし、科学ワークフロー自動化に自然にフィットする。

arXiv:2512.19458「An Agentic Framework for Autonomous Materials Computation」は材料の DFT 計算・構造最適化などの計算タスクの自動化を扱い、本論文の「理論発見」と相補的な「計算実行」の自動化を担う。二つを組み合わせると「データ収集 → 法則発見 → 計算検証」という閉じたループが構想できる。

## 5. どこまで広がるのか

### 未知の材料関係式の発見への道

本論文が実証したのは「文献に記載された既知法則の回復」（Hall-Petch・Paris 則）と「候補方程式の新規提案」（ひずみ修正 Kuhn）の初歩的なケースだ。真の価値は、文献に現れていない物質固有の経験則——例えば「特定のマルチプリンシパル合金の高温クリープ速度を組成から記述する法則」や「ペロブスカイト太陽電池の劣化速度を分子構造から記述する法則」——を発見することにある。このためには、LLM の事前知識にない「未知空間」で機能する探索能力が必要であり、現時点ではその能力は実証されていない。

### 材料データベースとの大規模統合

現フレームワークは単一データセット（数十〜数百点）を対象としているが、Materials Project（100 万件超の DFT 計算）・AFLOW・OQMD のような大規模データベースに接続すれば、「組成-物性の新規相関」「構造-相転移の法則」など人間がまだ体系化していない関係を発見できる可能性がある。ただしこの規模では「フィッティング結果の次元解析的チェック」「発見した式の物理的一貫性の自動検証」が不可欠になる。

### マルチモーダルデータへの拡張

現フレームワークは均質な表形式データ（$x$, $y$ の数値ペア）を前提とする。実験室では画像（電子顕微鏡像・X 線回折パターン）・スペクトル・テキスト注釈が混在する。マルチモーダル LLM（GPT-4V など）と組み合わせることで、「顕微鏡像中の組織構造パラメータを特徴量として自動抽出し、それを用いた経験則を発見する」という、より実際的な実験科学への応用が開ける。

## 6. 次に問うべきこと

### 「回復」と「発見」を分離する実験設計

本論文の核心的な未解決問題は「エージェントが方程式を『知っていた』のか『データから導いた』のか」の区別だ。これを検証するためには、LLM の訓練データに含まれないことが確実な「人工的な未知法則」に従うデータ（例：$y = \sigma_0 + k \sin(\pi/\sqrt{d})$ のような、教科書に載っていない形）をエージェントに与え、正しく発見できるかを試すブラインドテストが有効である。既知法則の回復における成功率が高くても、この種のブラインドテストで同様の性能が出なければ「記憶の引き出し」に過ぎないと判断できる。

### 物理的正しさの自動検証機構

本論文が示した最も深刻な問題は「もっともらしいハルシネーション」——R² の差わずか 0.0006 で誤った方程式が正しいものとほぼ区別できなかったケースだ。これに対する具体的な解決策として、次元解析チェック（生成された方程式が次元的に一貫しているか）、漸近挙動の検証（$d \to 0$ や $d \to \infty$ でのふるまいが物理的に妥当か）、パラメータの物理的範囲チェック（$\sigma_0$ が負にならないかなど）を自動的に行うツールをレジストリに追加することが考えられる。さらに根本的には、「複数の独立したデータセットで発見した方程式が同じ普遍定数を与えるか」という独立検証が、単一 R² 値よりも科学的信頼性の高い指標となる。

### 「発見した」方程式の物理的一貫性検証のための第一原理計算との統合

LLM エージェントが候補方程式を提案した後、その方程式が物理的に正当化できるかを DFT や分子動力学シミュレーションで検証するというクローズドループを構築することが、真の科学的価値をもつ発見に向けた自然なステップである。`2512.19458` が自律的材料計算フレームワークとして提案したアーキテクチャと本論文の方程式発見フレームワークを接続することで、「実験データ → LLM が方程式を提案 → 第一原理計算で検証 → 改訂」という反復的な理論構築ループが実現できる。

## 7. 基礎から理解する

### Hall-Petch 則の物理

Hall-Petch 則

$$\sigma_y = \sigma_0 + \frac{k_y}{\sqrt{d}}$$

の $d^{-1/2}$ という関数形は転位パイルアップモデルから導かれる。結晶粒内を運動する転位が粒界に到達して停止し、蓄積された転位群（パイルアップ）が隣接粒に応力集中を生じる。粒径 $d$ が小さいほど単位体積あたりの粒界面積が増え（$\propto d^{-1}$）、転位の平均自由行程が短くなる。パイルアップモデルでは、先端の応力集中が隣接粒の降伏強度を超えるために必要な外部応力が $\propto d^{-1/2}$ となることを示せる。

$\sigma_0$ は格子摩擦応力（Peierls 応力）に対応し、単結晶の降伏応力に近い。$k_y$ は粒界強化係数であり材料依存性をもつ（例：アルミニウムでは鋼より小さい）。本論文で得られた $\sigma_0 = 38.46$ MPa、$k = 9.48$ MPa·μm$^{0.5}$ は純鉄や低炭素鋼の典型的な値と整合する。

### Paris 則と Region II の意義

疲労き裂進展の全特性は S 字型の対数-対数曲線で表される。低 $\Delta K$ 域（Region I）では閾値 $\Delta K_{\rm th}$ 以下では進展しない；中間域（Region II）では Paris 則 $da/dN = C(\Delta K)^m$ が成立；高 $\Delta K$ 域（Region III）では不安定破壊に至る。Paris 則が適用される Region II の特定はエージェントの「材料物理的理解」を試す部分であり、全データに単純にフィッティングすると誤った結果が得られる。本論文でエージェントが自律的に傾き（対数-対数プロットでの勾配）が一定な領域を検出して Region II を選択したことは、暗黙的な物理的知識の応用を示している。

### Kuhn 方程式の量子力学的背景

Kuhn 方程式はポリエン系共役分子の粒子箱（particle-in-a-box）モデルに由来する。長さ $L$ の箱に閉じ込められた $N$ 個の π 電子のエネルギー準位は

$$E_n = \frac{h^2 n^2}{8mL^2}, \quad n = 1, 2, \ldots$$

HOMO は $n = N/2$、LUMO は $n = N/2 + 1$ の準位に対応し（$N$ が偶数の場合）、エネルギーギャップは

$$\Delta E = E_{N/2+1} - E_{N/2} = \frac{h^2}{8mL^2}(N + 1)$$

となる。$(1 - 1/N)$ の補正項は実際のポリエン系では端効果として現れ、有限長鎖での偏差を補正する。$N \to \infty$（無限長鎖）では $(1-1/N) \to 1$ となり、$\Delta E \to V_0$ という高分子極限が回収される。ヘリセンのような多環芳香族系では $L$ が $n$（環の数）に依存し、$N = 4n + 2$ の関係をもつ。

### ReAct ループの設計思想

ReAct は「言語モデルが推論（Reason）と行動（Act）を交互に実行する」パラダイムである。純粋な LLM（ツールなし）は多くの科学問題を解けないが、外部ツール（数値計算・データベース検索）があれば大幅に能力が拡張される。一方、単純なプログラムループは状況適応的な推論ができない。ReAct はこの二つの強みを統合する：LLM が状況を観察し「次に何をすべきか」を推論し、最適なツールを選択して実行し、その結果を観察して次の推論に活かす。

本論文での重要な実装上の選択は「エージェント状態」の設計だ。推論履歴・フィッティング済みパラメータ・検証指標が全て持続的に保存されるため、「以前に試みた式が失敗した理由」を LLM が参照しながら「別の形式を試すべき」という判断ができる。これが単純な 1 回の LLM 呼び出しとの本質的な違いである。

### 記号回帰との比較

古典的な記号回帰（遺伝的プログラミングベース）と本論文の LLM アプローチの違いを整理すると以下のようになる。

探索戦略の面では、遺伝的プログラミングはランダム突然変異と適者選択で構文木を進化させるため、初期集団次第で物理的に意味のない中間形式（例：$\sin(\log(x)) + x^3$）が頻繁に現れる。LLM アプローチは学習した科学知識から「物理的に妥当な形式」を最初に提案できる。

しかし LLM アプローチには「既知の法則へのバイアス」という弱点がある。LLM は文献に多く現れる式形を好む傾向があり、真に新規な形式の発見には不利かもしれない。

## 8. 専門用語の解説

**Hall-Petch 則（Hall-Petch Relation）**  
多結晶金属の降伏応力が結晶粒径の逆平方根に比例する経験則 $\sigma_y = \sigma_0 + k_y/\sqrt{d}$。転位パイルアップモデルから理論的に導かれる。本論文でエージェントが自律的に回復し、$\sigma_0 = 38.46$ MPa、$k = 9.48$ MPa·μm$^{0.5}$、$R^2 = 0.9499$ を達成した。

**Paris 則（Paris' Law）**  
疲労き裂進展速度の安定成長域（Region II）で $da/dN = C(\Delta K)^m$ が成立する経験則。材料依存のパラメータ $C$・$m$ が材料の破壊特性を特徴付ける。エージェントは自律的に Region II を特定してからフィッティングを行う必要があった。

**Kuhn 方程式**  
共役有機分子の HOMO-LUMO ギャップを π 電子数 $N$ と共役長 $L$ で記述する量子力学的方程式 $\Delta E = h^2(N+1)/(8mL^2) + V_0(1 - 1/N)$。GPT-4 は $(N+1)$ 因子を欠落、GPT-5 は $(1-1/N)$ 補正項を欠落した不完全な形を想起した。

**もっともらしいハルシネーション（Plausible Hallucination）**  
科学的に誤った方程式が標準的な統計検証指標（R²・RMSE）をパスしてしまう失敗モード。本論文での典型例は、Kuhn 方程式の正解と誤答の R² 差がわずか 0.0006 であったケース。「数値的適合度 = 科学的正しさ」という等号が成り立たないことを示す。

**ReAct（Reasoning and Acting）ループ**  
LLM が推論（Thought）→ 行動（Action）→ 観察（Observation）を反復するエージェントパラダイム。外部ツール（数値計算・データ取得）と LLM の推論を統合し、状況適応的なワークフローを実現する。Yao et al.（arXiv:2210.03629）が提案した。

**エピステミック自己認識（Epistemic Awareness）**  
「自分が何を知っており、何を知らないか」を評価する能力。GPT-5 は PDF 抽出失敗を認識して HTML 抽出に切り替えたが、GPT-4 はエラーメッセージを有効な出力として扱った。自律的科学エージェントにおいて「失敗を認識する能力」は「正確に答える能力」と同等に重要。

**記号回帰（Symbolic Regression）**  
数値データ $(x_i, y_i)$ から解析的数式 $y = f(x; \theta)$ を発見する手法。関数形式 $f$ そのものを（+・×・$\exp$・$\sqrt{}$ などの演算子の組み合わせから）探索する点で、パラメータのみを最適化する通常の回帰と異なる。PySR・AI Feynman などが代表的実装。

**機能的不安定性（Functional Instability）**  
開放的なモデリングタスク（正解がない問題）で、エージェントが実行毎に異なる関数形を生成する失敗モード。本論文ではひずみ修正 Kuhn 方程式で確認された。LLM が「探索」しているのか「でたらめを生成」しているのかの区別が困難。

**Region II（安定き裂進展域）**  
疲労き裂進展の S 字型 da/dN–ΔK 曲線における中間域であり、Paris 則が成立する。低 ΔK 域（閾値以下）・高 ΔK 域（不安定破壊域）と区別され、実用的な疲労設計に使われる。データ全域に Paris 則を単純に適用すると誤った結果が得られるため、Region II の自動識別が重要。

**ChainofThought（CoT）推論**  
LLM が最終答えだけでなく「推論ステップを明示」しながら回答するプロンプティング手法。本フレームワークの THOUGHT ステップがこれに対応し、「データのどの特徴に注目したか」「なぜこの方程式形式を選んだか」の明示的な記録を実現する。

## 9. まとめ

arXiv:2604.19789 は LLM エージェントが材料科学の支配方程式を自律的に発見（または回復）できることを、具体的なケーススタディと詳細な推論トレースによって初めて体系的に実証した。Hall-Petch 則・Paris 則という確立された方程式については、両モデル（GPT-4・GPT-5）が 7〜9 イテレーションで正確に回復し（R² = 0.95）、自律的な研究補助としての実用性を示した。

しかし本論文が最も重要な貢献としたのは成功事例の提示ではなく、失敗モードの分類である。Kuhn 方程式ケースで明らかになった「もっともらしいハルシネーション」——誤った方程式が R² の差 0.0006 でパスしてしまう——は、自律的科学エージェントにおける根本的な検証問題を提起する。数値的適合度指標は「科学的正しさ」の十分条件ではない。GPT-5 が PDF 抽出失敗を認識して代替策に切り替えたことは「エピステミック自己認識」の萌芽を示すが、GPT-4 にはこの能力が欠如していた。

ひずみ修正 Kuhn 方程式は「正解のない新規方程式候補の生成」という最も野心的なタスクであり、実行のたびに異なる関数形が生成される機能的不安定性が確認された。これは現在の LLM が「探索的モデリング」では一貫した自律研究者として機能するには至っていないことを示す。

LLM 駆動の材料理論発見が真の「発見」（ブラインドテストでの新規法則の同定・物理的整合性の自動検証・第一原理計算との閉ループ検証）へ成熟するための道筋は見えており、本論文はその出発点を示している。
