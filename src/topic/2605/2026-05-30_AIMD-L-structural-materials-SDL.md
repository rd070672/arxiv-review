# 構造材料のための自律実験室：AIMD-L

- 執筆日: 2026-05-30
- **要旨**: 電池・光触媒・薄膜などの機能材料では、AIと組み合わせた自律実験室（SDL）が急速に普及しつつある。しかし微細組織が性能を直接左右する構造材料、とりわけ高ひずみ速度・高圧といった極限環境下での特性試験は、自律化が著しく遅れていた。本記事では、ジョンズ・ホプキンス大学が構築した自律実験室 AIMD-L を取り上げ、レーザー衝撃試験（HELIX）・高エネルギーX線回折（MAXIMA）・ナノインデンテーション（SPHINX）を統合したロボット化プラットフォームが、いかにして従来比1000倍のスループットを実現し、組成傾斜 Cu-Ti 合金の多探針データセットを生成したかを解説する。加えて、完全自律型クローズドループ最適化に向けた未解決課題と、機械学習との連携可能性を論じる。

## 1. なぜ今このテーマか

材料ゲノムイニシアティブ（MGI）が 2011 年に掲げた「材料開発サイクルの半減」という目標は、機械学習と実験の自動化の組み合わせによって現実のものになりつつある。電池電極、有機合成、薄膜太陽電池、電気化学触媒といった機能材料の領域では、自律実験室（self-driving laboratory, SDL）が次々と報告されてきた。たとえば 2019 年のフレーザーグループによる薄膜材料 SDL では、ベイズ最適化と自動スパッタリング装置を組み合わせて光電気化学特性を効率的に探索した。2023 年の "A-Lab"（Szymanski ら）は多目標合成と XRD 分析を完全自動化し、電池材料の新規相を次々と合成してみせた。さらに近年の Born-Qualified フレームワーク（arXiv:2605.00639）のように、エネルギー・電子材料向けのより汎用的なアーキテクチャも登場している。

こうした成功例が相次ぐ一方で、見落とされてきた領域がある。それが**構造材料**——航空機のエンジン翼、ロケットノズル、装甲材、核融合炉の第一壁といった、極限の温度・圧力・ひずみ速度のもとで機械的性能を発揮しなければならない材料の世界だ。Miracle と Thoma（2024年）はこの問題を明示的に指摘し、構造材料の自律研究開発が大きく遅れている理由として三点を挙げた。第一に、機械特性の計算が困難であること。第二に、熱機械加工（圧延・鍛造・押出し）と試験体準備の自動化が難しいこと。第三に、微細組織の特性評価が本質的に多スケールであること。

機能材料では多くの場合、バルク微細組織はあまり重要ではない。どの相が合成されたかさえ分かれば、性能の概略はつかめる。しかし構造材料では、ナノスケールの析出物・転位・積層欠陥から、ミリスケールの結晶粒・繊維組織まで、あらゆる階層の微細組織が強度・靭性・疲労寿命を決定する。試験体の寸法そのものも機械的挙動に影響する（サイズ効果）。さらに高ひずみ速度試験——衝撃、爆発、弾丸貫通——は本質的に「速い」実験であるため、一見自動化に向いているように思えるが、発射装置の組み立て、試料位置合わせ、高価な計測機器の操作といった作業が専門家の手を必要としてきた。

こうした課題が重なることで、構造材料の SDL 化は機能材料に何年も遅れてきた。ところが 2026 年、この状況を変えようとする論文が登場した。ジョンズ・ホプキンス大学の Hufnagel らが構築した AIMD-L（Artificial Intelligence in Materials Design Laboratory）である。

## 2. 何が新しいのか

AIMD-L の核心は、「構造材料が特に必要とする三種類の計測」を、ロボット搬送系と統一ソフトウェア基盤によって有機的に統合した点にある。

### MAXIMA——バルク微細組織の高速スクリーニング

EBSD（電子後方散乱回折）は微細組織評価の金字塔的な手法だが、試料表面の電解研磨が必要であり、真空中での測定を要し、広視野のスキャンには時間がかかる。バルク内部を代表する情報が得られるかどうかも問題になる。

AIMD-L の解決策は、透過型高エネルギーX線回折（HEXRD）だ。MAXIMA（Multimodal Automated X-ray Investigation of Materials）は 24 keV の集光 X 線ビームを試料に垂直に入射させ、透過方向の 2D 回折パターンをピクセルアレイ検出器で収集する。透過配置を採るため、表面ではなく真のバルク（板厚全体）の微細組織が計測できる。空間分解能は 250 μm で、大型試料の面内スキャンが容易だ。しかも表面準備はほぼ不要であり、1 スキャンに要する時間はわずか 1 秒——1 日に数千スキャンが可能になる。これは EBSD の通常の測定速度と比較して、スループットで 2〜3 桁の改善に相当する。

さらに MAXIMA は X 線回折と同時に X 線蛍光（XRF）も収集する。XRF による組成計測を回折による相同定と同一スキャンで行えるため、組成傾斜試料における「どこに何の相が生じているか」を一挙に把握できる。

![Figure 1: AIMD-L における微細組織評価のスループットと忠実度のトレードオフ](https://arxiv.org/html/2603.06835v1/x1.png)
*図 1. 高エネルギーXRD（HEXRD）、EBSD、透過型電子顕微鏡（TEM）の速度・空間分解能比較。MAXIMA は忠実度をある程度犠牲にする代わりに、EBSD に対して 2〜3 桁高いスループットを達成する。この「スクリーニング→精査」の階層的アプローチが AIMD-L の微細組織評価戦略の基本思想である。（Hufnagel et al., arXiv:2603.06835, CC BY-NC-ND 4.0）*

### HELIX——衝撃試験の民主化

高ひずみ速度試験の代表格であるプレート衝撃試験は、火薬式・ガス銃式の大型装置を用い、試験 1 件ごとに相当な準備・費用・専門知識を要する。1 日数件がせいぜいという世界だ。

HELIX（High-throughput Extreme Laser Impact eXperiments）はこれを抜本的に変える。アルミニウム箔をガラス基板にエポキシで接着した「フライヤースタック」に、5×5 の配置で直径 1.5 mm の円形ディスクをレーザーカットしておく。実験時には駆動レーザーがエポキシを瞬間的に剥離させ、フライヤーディスクが最大 2000 m/s で試料に衝突する。衝撃波が試料背面に到達すると、PDV（光子ドップラー速度計）が背面粒子速度の時間波形を記録する。この波形からユゴニオ弾性限（HEL）とスポール強度が自動解析される。1 セットのフライヤースタックで 25 発の衝撃実験が行え、発射・解析・次の試料セッティングはすべてロボットが行う。

![Figure 6: HELIXの実験配置とPDV波形の一例](https://arxiv.org/html/2603.06835v1/x5.png)
*図 2. （a）HELIXの実験パッケージ断面図。駆動レーザーがフライヤーディスクを加速し、試料への衝突でつくられた衝撃波をPDVで計測する。（b）Cu-Ti系試料（5.65 at.% Ti）の実測PDV波形。点Aがユゴニオ弾性限（HEL）、B-C間が衝撃応力、C-D間がスポール強度に対応する。（Hufnagel et al., arXiv:2603.06835, CC BY-NC-ND 4.0）*

このアプローチにより、1 日に数千発という桁違いのスループットが実現し、コストは従来の約 1/1000 になる。衝撃物理分野において、ここまで系統的な組成・微細組織・ショック特性の相関研究が可能になるのは史上初めてといってよい。

### SPHINX——ナノインデンテーションの自動化

市販の高精度ナノインデンター（KLA G200X）を AIMD-L 搬送系に統合するには、ロボットアームがアクセスできるよう機械的改造と、独自 API の開発が必要だった。Hufnagel らは KLA との共同作業でこれを実現し、OPC UA プロトコルを通じた遠隔制御を可能にした。SPHINX（Scanning Probe for High-resolution INdentation eXperiments）は硬さ（H）と弾性率（E）を、連続剛性法（CSM）を使って深さ方向のプロファイルとして高分解能で取得する。これにより、組成傾斜試料上の位置ごとの機械特性マップが自動的に生成される。

### 搬送・データ統合の設計

AIMD-L の強みは計測装置の性能だけではない。6 台の協調ロボット（UR10e）が試料ホルダーをベルト搬送系（最大 225 ホルダー同時循環）から各ステーションへ受け渡す。試料ホルダーには QR コードが付き、IGSN（International Generic Sample Naming）の永続識別子と紐付けられる。各測定データは OpenMSIStream を使って即座にデータポータルに送信され、到達と同時に自動処理ワークフローが起動する。データは 200 Gb/s でジョンズ・ホプキンス大学のブルームバーグデータセンター（1.5 PB のオブジェクトストレージ）に格納される。

制御層では OPC UA サーバーが実験ステート管理を一元化し、「人間ユーザー」と「AI エージェント」を対等のクライアントとして同一 API で扱う設計になっている。AI エージェントが次の実験計画を API に投入すれば、それがそのまま実行指示になる——これが完全な自律クローズドループへの扉を開く。

![Figure 4: AIMD-Lの制御信号とデータフロー概要](https://arxiv.org/html/2603.06835v1/x4.png)
*図 3. AIMD-L における制御信号（上）とデータフロー（下）の概略図。人間ユーザーまたは AI エージェントが API を通じてランマネージャに指示を発行し、各ステーションで生成されたデータがデータポータルにストリームされる。到達イベントが自動データ処理を起動し、結果が即座にエージェントにフィードバックされる。（Hufnagel et al., arXiv:2603.06835, CC BY-NC-ND 4.0）*

### 実証実験：Cu-Ti 組成傾斜合金

AIMD-L の能力実証として、Hufnagel らは組成傾斜 Cu-Ti 合金フォイル（Ti 含有量 0.1〜7 at.%）を作製した。大型マグネトロンスパッタ装置でチタンターゲットを部分遮蔽して傾斜を生じさせ、40×40 mm のフォイル（厚さ約 200 μm）を多数製作。900°C/10 時間の真空アニール後に油中急冷することで、ナノラミネート構造を均質固溶体に変換した。

MAXIMA で組成を XRF 計測しながら XRD を行い、HELIX で各組成のショック特性を、SPHINX でナノインデンテーション特性を取得した。その結果が図 4 に示されている。

![Figure 10: Cu-Ti組成傾斜試料の多探針データセット](https://arxiv.org/html/2603.06835v1/x9.png)
*図 4. AIMD-L の三主要ステーションが生成した Cu-Ti 系多探針データセット。弾性率・硬さ（SPHINX）、格子定数（MAXIMA）、ユゴニオ弾性限（HELIX）を Ti 組成の関数としてプロット。赤丸は XRD で Cu₄Ti 析出が確認された領域を示す。弾性率・HEL・格子定数は～3 at.% Ti で極大を示し、硬さは単調増加する。（Hufnagel et al., arXiv:2603.06835, CC BY-NC-ND 4.0）*

## 3. どこまで分かったのか

Cu-Ti 系での実証データが示す最も興味深い点は、「同じ試料の塑性変形抵抗を表す」はずの硬さと HEL が、Ti 組成に対して異なる傾向を示したことだ。硬さ（SPHINX）は Ti 濃度の増加とともに単調に増加するが、HEL（HELIX）は約 3 at.% Ti で極大を迎えたあと頭打ちになる。弾性率や格子定数も HEL と同様に ～3 at.% で極大を示す。

この乖離は何を意味するのか。Hufnagel らは二つの違いを指摘する。一つはひずみ速度の差だ。ナノインデンテーションは典型的に 10⁻³ s⁻¹ 程度のひずみ速度で行われるが、HELIX の衝撃実験では 10⁶ s⁻¹ を超える。高ひずみ速度では熱的活性化機構が寄与できず、変形を担う転位の挙動が変わる。もう一つはサンプリング体積の差だ。ナノインデンテーションは局所的な数 μm³ 程度の体積を計測するが、HELIX は試料の板厚全体を通した「バルク」の応答を反映する。両者が同じ組成傾向を示さないことは、むしろ当然だとも言える——そして、それこそが「一つの特性ではなく、複数の相補的探針からデータを取る」意義を示している。

この多探針アプローチは、AI/ML モデルの訓練に特に価値がある。単一の特性データで訓練したモデルは過学習しやすく、他の特性への汎化が難しい。しかし硬さ・弾性率・HEL・格子定数・組成情報が揃ったデータセットがあれば、ひずみ速度依存性の物理を学習できるモデルや、微細組織パラメータと性能をつなぐマルチタスクモデルの構築が現実的になる。

関連研究との比較という観点では、Born-Qualified SDL（arXiv:2605.00639）との違いが際立つ。Born-Qualified は薄膜・電子材料に向けた包括的な SDL フレームワークであり、Bayesian 最適化や自動合成ループを含む。これに対して AIMD-L は「特性評価」に特化しており、閉ループ合成はまだ統合されていない。この制約は自律化の観点では重要な課題であるが、特性評価そのものに桁違いのスループットをもたらしている点で独自の価値を持つ。

ナノインデンテーションの自動化という個別の課題については、Chawla ら（arXiv:2504.18525）がワークフローの最適化を論じているが、AIMD-L のように多ステーション SDL の一部として完全統合した例は珍しい。また nanoindentation データからの機械学習（たとえば CuCr 合金での教師なし学習、arXiv:2309.06613）は組成傾斜試料への適用という観点ではまだ黎明期にある。AIMD-L が生成するような組成連続的データセットは、この研究を加速させる土台になりうる。

一方で AIMD-L 自身の限界も明確に述べられている。XRF が原子番号 12 未満の元素（Mg など）を測定できないこと、高温ナノインデンテーションがまだ自動化されていないこと、そして最大の制約として「微細組織を操作する機能」——すなわちインサイチュ熱処理や塑性加工——が搭載されていないことが挙げられている。現時点では「特性評価が極めて速い」システムであって、「合成→評価→合成のクローズドループ」が自動で回るわけではない。

## 4. 研究の流れの中でどう位置づくか

材料の高スループット研究の流れは、2000 年代前半のコンビナトリアル薄膜合成にさかのぼる。透過型電子顕微鏡・EBSD などの計測手法の進歩と組み合わせることで、組成空間の系統的探索が進んだ。MGI（2011年）はこの潮流を政策的に後押しし、データ共有インフラ・計算材料学との連携を促した。

SDL への本格的な移行が始まったのは 2019 年前後だ。Hillier グループの薄膜 SDL（arXiv:1906.05398）は自動スパッタ装置とベイズ最適化を組み合わせ、光電気化学特性の最適化を自動化した。この論文は「機能材料向け SDL」の一つの定型を確立した。自動合成→自動計測→AI による次実験提案、というサイクルだ。

その後、電気化学インピーダンス分光（EIS）の自動解析（arXiv:2604.27266; EIS-RL-AutoREC）や、電気化学プラットフォーム MAP-E（arXiv:2603.09845）など、機能材料の SDL はますます高度化していった。それらに共通するのは、計測対象の特性が比較的測定しやすく、試料準備がシンプルであるという条件だ。

構造材料が SDL 化に乗り遅れた根本は、この「試料準備と計測の困難さ」にある。衝撃試験で使う試料は平滑な両面が必要であり、ナノインデンテーションでは表面粗さが測定値に影響する。試料寸法そのものが力学応答に影響する（サイズ効果）ため、試料形状を一定に保つことが重要だが、それは自動化を難しくする。AIMD-L が採用した 40×40 mm のフォイルという標準ホルダーは、こうした制約をいかに「規格化」するかという工夫の結晶だ。

HELIX の前身となる高スループット衝撃試験システムの研究は Ramesh グループで長年行われてきた。レーザー駆動マイクロフライヤー法それ自体は 1990 年代から知られているが、フライヤーの事前カット、ロボットによる組み立て、PDV の自動解析（Diamond and Ramesh 2024）を組み合わせたシステムとして HELIX は完成した。AIMD-L は HELIX をより大きな SDL アーキテクチャに統合することで、衝撃物理とマテリアルズ・インフォマティクスをつなぐ架け橋となった。

MAXIMA の設計思想、すなわち「忠実度は低くても良いから圧倒的に速い計測でスクリーニングし、気になる領域だけ EBSD や TEM で精査する」という階層的アプローチは、SDL 全般に広く通用するパラダイムを提示している。自律実験室が生成するデータの意義は「精密な一点計測」ではなく「広い設計空間の俯瞰」にあるからだ。アジェンティックな AI がデータを参照しながら次の実験領域を絞り込む、という使い方に MAXIMA のデータは相性がいい。

## 5. どこまで広がるのか

AIMD-L の実験系は Cu-Ti 系で実証されたが、その設計は汎用的だ。40×40 mm のフォイルを作製できる材料であれば、Al 合金・Ti 合金・高エントロピー合金（HEA）・セラミックスなど幅広い材料系に適用できる。とくに HEA は組成次元が高く、膨大な組成空間を探索するために大量のデータが必要であるため、AIMD-L のスループットが特に有利に働く。

極限環境という観点では、HELIX の温度制御機能を生かした高温衝撃試験の自動化が次の自然な拡張だ。現状ではオフラインで試料を加熱してから測定している部分があるが、これをインサイチュ化できれば、高温時の耐衝撃性探索が格段に加速する。また HELIX のコンセプト（小型レーザー駆動 + PDV）は、軽量化・コンパクト化が進んでいるため、放射光施設や中性子施設の実験ハッチに組み込んでインサイチュ XRD を併用する可能性も否定できない。

核融合炉・核分裂炉の照射環境で問題になる照射欠陥の機械特性への影響は、ナノインデンテーションで調べることが多い。SPHINX のような自動化ナノインデンテーションと HELIX の組み合わせは、照射材料の迅速評価に直結しうる。放射性試料を扱うという特殊性はあるが、ロボット化というコンセプト自体は照射試料取扱いの安全性向上という文脈で歓迎される。

データアーキテクチャの観点では、AIMD-L が採用した IGSN DOI による試料トレーサビリティと、DataCite を通じた公開メタデータリンクのスキームは、ほかの複数施設のデータと連携できる可能性を持つ。MIT の MRSEC、ANL の APS、ORNL の SNS といった拠点の計測データと AIMD-L のデータをリンクさせることで、より包括的なマルチスケールデータベースが構築できる。この発展の方向は、Towards Agentic Intelligence for Materials Science（arXiv:2602.00169）が描く分散型エージェント研究のビジョンとも符合する。

一般化の際に破綻しそうな条件も意識しておく必要がある。AIMD-L の試料フォーマット（薄いフォイル）は、バルク熱間圧延材や鍛造品とは微細組織が異なりうる。スパッタ蒸着→アニールという手法では、鍛造・圧延で生じる加工テクスチャや繊維状組織は再現できない。したがって AIMD-L で得たデータは「バルク構造材料の代替」ではなく、「探索用の近似データ」として使い、有望な組成を絞り込んでから実機材料で検証する、という使い方が現実的だ。

## 6. 次に問うべきこと

### クローズドループ最適化の実現

現在の AIMD-L が「特性評価」に特化していることは明示されている。次の問いは、「どのようにして合成→特性評価→合成のループを閉じるか」だ。Hufnagel らは簡単な熱処理（スポットレーザー焼鈍）の統合を検討中だと述べているが、圧延や鍛造といった熱機械加工は難しい。

一つのアプローチは、外部の加工施設（ロボット圧延機など）と AIMD-L を試料搬送ロボットでつなぐ「連邦型 SDL」だ。試料が AIMD-L から加工施設に移り、加工後に戻ってくる。このスキームは著者らも展望として言及しており、アジェンティック AI が複数施設間の計画を立案する構図になる。何が仮説として立てられるかといえば、「組成 X のある処理サイクルを経た試料が最適な HEL を示す」という経験的モデルを AI が学習し、次の処理条件を提案するというループだ。これが実現するには、AIMD-L のデータだけでなく、加工履歴を含むプロセス—微細組織—性能の統合データベースが必要になる。

### 少数データからの外挿

構造材料の組成空間は広い。高エントロピー合金であれば 5〜6 元素系が現実的で、組成点は事実上無限にある。AIMD-L のスループットは従来比1000倍とはいえ、全空間を網羅するには足りない。重要な問いは「何点のデータで、どの精度の性能予測モデルが作れるのか」だ。

機能材料向けベイズ最適化の文献では、数十点から数百点でかなりの精度が達成される例が多い。しかし HEA の衝撃特性の場合、ひずみ速度・温度・微細組織の三重依存性があるため、必要なデータ数は一桁以上多くなる可能性がある。少数データからの効率的学習（アクティブラーニング、物理情報を取り込んだ機械学習）が AIMD-L データとどの程度相性が良いかを検証することは、急務の課題だ。

電気化学 SDL の MAP-E（arXiv:2603.09845）では、アクティブラーニングで探索効率を大きく改善した例が示されている。同様のアプローチが衝撃特性の組成探索にも使えるか——具体的には、次にどの組成点を試験するべきかを HEL の不確かさ推定に基づいて決定するエージェント——は、今後の研究方向として明確に開かれている。

### 微細組織情報の活用

MAXIMA から得られる XRD データには、相の種類・格子定数・テクスチャーの情報は含まれるが、結晶粒径（マイクロスケール以上の場合）・転位密度・析出物の形態といった詳細は得られない。AIMD-L のデータだけでは、「なぜその組成でその特性が出るのか」の物理的機構まで理解することは難しい。

仮説として立てられるのは、「XRD 由来のマクロ微細組織指標（相体積分率・格子定数）と機械特性の間の相関を機械学習でモデル化できれば、少数の EBSD/TEM データで補正できるモデルが構築できる」というものだ。検証には、AIMD-L のデータと外部高分解能計測（放射光 EBSD、電子線トモグラフィ）を組み合わせた学習実験が必要になる。これが実現すれば、「大量の低解像度データ ＋ 少量の高解像度データ」という多忠実度学習のアーキテクチャが構造材料に根付くことになる。

### 動的特性の多次元化

HEL とスポール強度は衝撃応答の二つの指標に過ぎない。疲労亀裂進展速度、動的破壊靭性、応力腐食割れ感受性といった特性は、現在の HELIX では計測できない。これらを自動化するための手法開発——たとえば miniaturized fatigue test の自動化、or 衝撃後の亀裂の自動 X 線 CT 評価——は、次の十年の課題として存在する。どのような装置設計が AIMD-L 型の「フォルムファクタ」に適合しうるかを論じることは、構造材料インフォマティクスの設計指針を描くことと同義だ。

## 7. 基礎から理解する

### ユゴニオ弾性限（HEL）とスポール強度

衝撃波（shock wave）は固体中を超音速で伝播する圧力不連続面だ。衝撃波が固体に入射すると、まず弾性的に圧縮される（弾性前波）。圧力が一定値を超えると塑性変形が始まり、弾性波から塑性波への分離が生じる。この遷移圧力が**ユゴニオ弾性限（Hugoniot elastic limit, HEL）** だ。HEL は「衝撃的な負荷に対する降伏強度」に相当し、準静的な硬さや降伏強度とは理論的に関係付けられるが、ひずみ速度依存性の違いから数値は一致しない。

HEL は PDV（Photon Doppler Velocimetry）で計測した背面粒子速度の時間波形から読み取る。弾性前波が背面に到達すると速度が跳び上がり（点A）、次いで塑性波が到達してさらに上昇する（点B〜C）。衝撃波が試料背面で反射し引張波になると、内部に引張応力が発生し、ある強度を超えると試料が内部破断（スポール）する。このスポールの強さが**スポール強度**として波形の落ち込みから算出される。HELIX は HEL とスポール強度の両方を自動的に解析する。

### 高エネルギーX線回折（HEXRD）による相同定

X 線回折は結晶格子に由来する干渉縞（ブラッグ反射）を検出することで、物質の結晶相を同定し、格子定数や結晶粒配向（テクスチャー）を定量化する。MAXIMA が採用する透過配置 HEXRD では、フォトンエネルギーが高い（24 keV）ことで X 線の透過深さが大きくなり、表面ではなく板厚全体のバルク情報が得られる。2D 検出器に映し出されたデバイ＝シェラーリングを円周方向に積分することで、従来の 1D 粉末 XRD 図形が得られ、参照データベースとの照合で相同定が行われる。XRF では、入射 X 線で励起された元素固有の蛍光 X 線の波長を分析することで元素組成が得られる。

### ナノインデンテーション（Oliver-Pharr 法）

ダイヤモンドの Berkovich 三角錐圧子を試料表面に押し込み、荷重（P）と変位（h）の曲線を連続的に記録する。**Oliver-Pharr 法**では、除荷曲線の接触剛性 S = dP/dh|max から真の接触面積 A を計算し、硬さ H = P_max / A、弾性率 E_r = (π^1/2 / 2) × S / A^1/2 として求める。Er は圧子と試料の複合弾性率であり、圧子の弾性定数を差し引いて試料単体の弾性率 E が得られる。連続剛性法（CSM）では荷重に微小振動を重畳することで、押し込み深さの関数として硬さと弾性率の連続プロファイルを取得できる。SPHINX では CSM を活用した深さ分解能の高い計測が自動で行われる。

## 8. 専門用語の解説

**ユゴニオ弾性限（Hugoniot elastic limit, HEL）**: 衝撃波による圧縮において、弾性変形から塑性変形へ移行する臨界圧力。高ひずみ速度（10⁶ s⁻¹ 以上）における動的降伏強度に相当する。準静的降伏強度とは機構は類似するが、ひずみ速度依存性の違いから数値は概して高い。AIMD-L では HELIX の PDV 波形から自動算出される。

**スポール強度（spall strength）**: 衝撃波の反射によって生じる引張応力が試料内部に達したときの動的破壊強度。PDV 波形の特定のプルバック信号から計算される。耐衝撃材料の設計指標として重要。

**PDV（Photon Doppler Velocimetry, 光子ドップラー速度計）**: 連続波レーザーの後方散乱とドップラー効果を利用して、試料背面の粒子速度を時間分解能 ns オーダーで測定する手法。衝撃試験における標準的な速度計測手段。HELIX では PDV 計測が自動化されており、すべての衝撃ショットで記録される。

**HEXRD（High-Energy X-ray Diffraction, 高エネルギーX線回折）**: 通常の X 線回折（Cu Kα 線 8 keV 等）より高フォトンエネルギー（20 keV 以上）を使用することで、厚い金属試料を透過してバルク微細組織情報を取得する手法。放射光施設や専用 X 線源で可能。MAXIMA は 24 keV の集光 X 線を使い、透過配置で 1 秒以内に回折パターンを取得する。

**XRF（X-ray Fluorescence, X線蛍光）**: X 線照射によって励起された元素固有の蛍光 X 線を分析することで、元素組成を非破壊・空間分解で測定する手法。MAXIMA では XRD と同時計測が可能で、組成傾斜試料の組成マッピングに使用される。

**SDL（self-driving laboratory, 自己駆動研究室）**: 実験計画・実行・データ解析・次実験提案のサイクルを AI/ロボットが自律的に繰り返す自動化実験室。「AI 駆動材料開発」の実験的実現形態。機能材料では広く普及しつつあるが、構造材料への応用は AIMD-L が先行事例となっている。

**OPC UA（OPC Unified Architecture）**: 産業オートメーションで広く使われるオープン通信規格。機器メーカーに依存しない相互運用性を提供し、状態管理・監視・リアルタイム制御を統一インターフェースで実現する。AIMD-L ではランマネージャと各ステーションの通信に採用されており、人間ユーザーと AI エージェントを同等に扱える制御基盤を提供する。

**OpenMSIStream**: ジョンズ・ホプキンス大学が開発したオープンソース Python ライブラリで、実験室の多様な計測機器からのデータを Apache Kafka を通じてリアルタイムでストリーミングし、自動処理ワークフローにつなげる。AIMD-L の「データ到着トリガー型ワークフロー」の実装基盤。

**組成傾斜材料（compositionally graded materials）**: 一つの試料内部で組成を空間的に変化させた材料。スパッタリング時のターゲット遮蔽や共蒸着の傾斜制御で作製される。組成空間を連続的に探索できるため、SDL における高効率なコンビナトリアル探索の手段として有用。AIMD-L では 40×40 mm フォイルに 0.1〜7 at.% Ti の傾斜を設けた Cu-Ti 試料が用いられた。

**サイズ効果（size effect）**: 材料の機械特性が試験体寸法に依存する現象。マイクロピラー圧縮試験など微細試験では「小さいほど強い」傾向が知られる（Hall–Petch 則とは別のスケール依存性）。AIMD-L が 200 μm 厚のフォイルを採用した背景には、薄膜（nm オーダー）とは異なる「バルク代表的」微細組織を実現しつつ、衝撃試験の一次元解析が適用できる厚さ範囲に収めるという工夫がある。

**ナノインデンテーション（nanoindentation）**: ダイヤモンド圧子を nm 精度で材料に押し込み、荷重—変位曲線から硬さ・弾性率を局所的に計測する手法。連続剛性法（CSM）により深さ方向のプロファイルも取得できる。SPHINX では商用ナノインデンターを改造し、AIMD-L の搬送系・制御系に統合することで全自動計測を実現している。

## 9. まとめ

AIMD-L は、構造材料向けに設計された世界初の本格的な自律・高スループット実験室として、機能材料 SDL では見落とされてきた問題領域に切り込んだ。三種の特性評価ステーション（衝撃試験・高エネルギーXRD・ナノインデンテーション）をロボット搬送系と統一データ基盤でつなぎ、衝撃試験で従来比1000倍、微細組織計測で100倍以上のスループットを実現した。Cu-Ti 系の組成傾斜試料における多探針データセットは、塑性変形抵抗の複数側面——硬さと HEL——が組成依存性において必ずしも一致しないことを明らかにし、多角的なデータが AI/ML モデルの訓練に不可欠であることを端的に示した。

ただし現時点では、AIMD-L はあくまで「評価」に特化したプラットフォームであり、合成や熱機械加工との統合は今後の課題だ。クローズドループ最適化、すなわち AI エージェントが評価結果に基づいて次の合成条件を提案し、外部施設と連携してその材料を作り、再び AIMD-L で評価するというサイクルは、まだ実装されていない。XRF・XRD で得られる微細組織情報の解像度も EBSD には及ばず、「なぜその特性が出るのか」という因果メカニズムの理解にはより高分解能な計測との組み合わせが必要だ。

それでも、AIMD-L が切り拓いた「構造材料のデータ駆動型探索」という地平は、重要性と緊急性の両面で見過ごせない。航空宇宙、防衛、核融合、極限環境産業のいずれにおいても、材料の動的特性に関するデータは依然として乏しく、機械学習に耐えうるデータベースが整備されていない。AIMD-L がそのボトルネックを解消する起点になるとすれば、構造材料の SDL はこれから急加速するフェーズを迎えることになるだろう。
