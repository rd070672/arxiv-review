  #   details: 材料合成、熱処理、薄膜形成、組織制御を通じて、材料のつくり方と機能の関係を探究します。プロセス・構造・特性の連関を明らかにし、高性能磁性材料や機能性材料の設計指針を築きます。

  - title: 電子構造・物性物理
    details: 電子状態、磁性、輸送現象、相転移に着目し、材料の基本的な物理特性を理解します。実験と理論を組み合わせ、電子・スピン・格子の相互作用が生み出す多様な物性を解明します。

  - title: 計算材料科学
    details: 第一原理計算や数値シミュレーションを活用し、電子・原子レベルから材料機能の発現機構を解析します。実験では直接見えにくい内部自由度を可視化し、材料設計や応答予測へと展開します。

  - title: 放射光・量子ビーム
    details: 放射光、X線、電子線などの先端計測を用いて、原子配列、局所構造、電子状態、磁気状態を高精度に調べます。元素選択的かつ局所的な情報を引き出し、機能発現の本質に迫ります。

  # - title: スピン機能材料
  #   details: 電子スピンを活用した材料機能の理解と制御に取り組みます。磁気異方性、磁歪、スピン輸送、磁化ダイナミクスを基盤として、低消費電力スイッチングや磁気センシングへの応用を目指します。

  # - title: フォノン・熱輸送
  #   details: 格子振動（フォノン）の生成、伝播、散乱、相互作用に注目し、熱やエネルギーの流れを理解・制御します。スピンや電子との結合も視野に入れ、振動自由度を活用した新しい機能創出を探ります。

  # - title: 非平衡ダイナミクス
  #   details: 外場駆動、急冷、緩和、ゆらぎ、履歴依存、非線形応答など、平衡状態から外れた物質の時間発展を扱います。相変化や磁化反転の過程を通じて、動的機能の発現原理を明らかにします。

  # - title: 量子機能デバイス
  #   details: 量子スピン、量子相関、トポロジカル状態を活用した新しいデバイス機能の創出を目指します。量子ビーム計測や第一原理計算と連携し、量子マテリアルの特性を引き出す設計指針を築きます。

  - title: マテリアルズ・インフォマティクス
    details: 材料の構造・電子状態・磁気状態・動的応答を情報として読み解き、材料機能の設計原理を探究します。複雑な材料現象の理解を、次世代エネルギー・情報デバイス材料の創出へとつなげます。

    # - title: マルチフィジックス解析
    # details: 電磁場、熱、応力、磁化、原子拡散などが相互に結合した材料応答を解析します。第一原理計算、連続体シミュレーション、フェーズフィールド、有限要素法を組み合わせ、実材料における複雑な機能発現を多階層的に理解します。
